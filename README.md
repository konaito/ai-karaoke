# 愛を伝えるだとか / KARAOKE

このディレクトリは、歌手`konaito`の`愛を伝えるだとか`一曲だけの静的PWAです。`VERSE`や`CHORUS`は歌唱セクション名です。音源・歌詞・ボーカル低減・マイクの音程検出はブラウザ内で動き、サーバーへ音声データを送信しません。

メイン画面はスクロールレスの一画面完結型です。日本の業務用カラオケの歌唱画面を参考に、背景映像を全面に敷き、現在の歌詞を大きく、次の歌詞を下に2行テロップとして表示します。曲の設定・曲構成ジャンプ・マイク音程モニターは歌唱画面を邪魔しないドロワー／オーバーレイに分離しています。

## ローカルで確認

```bash
cd karaoke
python3 -m http.server 4173
```

`http://localhost:4173/` を開きます。`file://` 直開きでは、Service WorkerとWASMのために正しく動作しません。

## PWAの更新

GitHub Pagesに新しい`sw.js`が配信されると、Service Workerが新しいキャッシュを準備して待機します。アプリは起動時・タブ復帰時・フォーカス時・15分ごとに更新を確認し、歌唱中に再生を勝手に中断しないよう「更新があります」ボタンを表示します。ボタンを押すと待機中のWorkerへ切り替え、`controllerchange`後にページを再読み込みします。

更新処理では`CACHE_NAME`と`app.js`／`styles.css`のクエリバージョンを更新し、古いキャッシュを`activate`時に削除します。初回の更新機能自体を配信した直後だけは、旧版のService Workerを確実に切り替えるため、インストール済みアプリを一度再起動してください。

## WASMを再ビルド

```bash
./karaoke/scripts/build-wasm.sh
```

`wasm/src/lib.rs` のDSPは、中央定位の高域成分を抑え、低域の中央成分を残すボーカル低減と、マイクのRMS/自己相関ピッチ検出を担当します。歌唱位置は`alignment.json`のローカル解析済み文字タイムラインで追い、現在行の各文字を実測時刻に合わせて塗ります。

## GitHub Pages

`.github/workflows/karaoke-pages.yml` は `main` の `karaoke/` 配下が更新されたとき、ディレクトリをそのままPagesへデプロイします。GitHubリポジトリの Settings → Pages → Source を `GitHub Actions` に設定してください。

## 日本のカラオケ採点との関係

DAMの精密採点Ai/DX-GとJOYSOUNDの分析採点AIを調査し、歌唱画面と採点結果画面を分ける設計にしています。公式説明では、歌唱中はガイドメロディーに対する歌唱軌跡、音程の一致、こぶし・しゃくり・フォール・ビブラートなどをリアルタイムに表示し、歌唱後に音程・安定感・表現力／抑揚・ロングトーン・テクニックなどをまとめて確認します。DAMはAi感性メーター／ボーナス、JOYSOUNDはAIゲージ／AIボーナスという独自要素を持つため、同じ「採点」と呼んでも内部計算は各社固有です。

このアプリの現在のマイク画面は、音程と声量の**練習モニター**です。DAM／JOYSOUNDと同等の採点を実装したとは表示しません。正解メロディーの音符列、フレーム単位の歌唱ピッチ、無声音・子音・発声開始の扱い、区間集計、歌唱技法検出、結果画面の集計が揃って初めて、ローカル練習採点として実装できます。

参考にした公式情報:

- [精密採点Ai（カラオケDAM公式）](https://www.clubdam.com/contents/saiten/seimitsusaiten_ai.html)
- [精密採点DX-G（カラオケDAM公式）](https://www.clubdam.com/contents/saiten/seimitsusaiten_dx_g.html)
- [分析採点AI＋/AI（JOYSOUND公式）](https://www.joysound.com/web/s/joy/bunseki)
- [分析採点AI＋/AIの遊び方（JOYSOUND公式）](https://www.joysound.com/web/s/function/bunseki)

## 既知の制約

歌詞タイミングは既知の歌詞を正として、ローカルの日本語`faster-whisper-small`が返した発声区間を文字単位へ展開したものです。従来のBPMグリッドより厳密ですが、歌唱専用の音素強制アライメントや正解メロディーとの比較ではありません。低信頼度の文字も`alignment.json`に残しています。マイク画面は音程モニターであり、採点画面ではありません。

このWAVは完成済みのステレオミックスで、分離済みボーカル/伴奏ステムではありません。そのため、アプリの「ボーカル低減」は機械学習による完全なステム分離ではなく、中央定位成分をWASMで抑える方式です。声の残響や中央のスネア/ベースが少し残る場合があります。
